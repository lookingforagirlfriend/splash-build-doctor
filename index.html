Supported build errors

This release recognizes five categories: project or wrapper problems, missing tasks, SDK configuration errors, Java/build-tool compatibility errors, and unverified APK output. It does not inspect your filesystem, run Gradle, or automatically repair a project.

Frequently asked questions

Does my log leave my device?

This implementation makes no network requests with your log and uses no browser storage. Exported reports include matched log lines; review them before sharing.

Does this fix or build my project?

No. It provides rule-based explanations and verification steps. It does not execute shell commands or modify project files.

What if no pattern matches?

That means the current rules did not recognize the input, not that your build passed. Inspect the original failure and nearby causes.

Is payment required?

No. Support is optional and does not unlock diagnostics or guarantee a repair.
